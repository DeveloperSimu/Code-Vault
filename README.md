# 💻 How to Use

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Navigate to the desired language/category:

```bash
cd C
```

Compile a C program:

```bash
gcc program.c -o program
```

Run:

```bash
./program
```

### Windows

```powershell
gcc program.c -o program.exe
.\program.exe
```
